# StarPie 桌宠交互与中心核心圆视觉解耦设计方案

## 1. 背景与目标

在桌面宠物等外部召唤源（桌宠点击唤出轮盘）或极简/透明桌面交互场景下，部分用户希望隐藏轮盘中心的中心圆视觉元素（包括中心圆底色、边框、图案与文字），以呈现完全通透的“环形扇区轮盘”体验，甚至在桌宠唤出时让桌宠处于轮盘视觉的正中心，不被中心核圆遮挡。

本方案在 StarPie 宿主中引入 `ShowCoreCircle`（默认 `true`），实现核心圆视觉呈现与死区判定逻辑的严格解耦。

---

## 2. 设计决策与解耦架构

### 2.1 视觉呈现与死区判定严格解耦

- **视觉层**：
  - `RadialWindow`：当 `ShowCoreCircle == false` 时，将整个中心容器 `CoreGrid.Visibility` 设为 `Visibility.Collapsed`。
  - `SettingsWindow.RenderLiveWheelPreview`：将预览中心容器 `_previewCoreGrid.Visibility` 设为 `Visibility.Collapsed`。
  - 中心覆盖层（`CoreSelectionOverlay`）、中心动作文字（`CoreSelectionTextPanel`）、音量百分比提示（`CoreVolumeText`）及各风格渲染器附加的中心动态装饰全部随容器彻底隐藏，杜绝在轮盘中心留下空心线框、毛玻璃残影或文字断片。
- **判定层**：
  - `GestureController` 与 `StickyWheelSession` 中的死区判定半径 `CoreDeadzoneRadius`（及回退公式 `Math.Min(CoreRadius, DragThreshold * 0.6)`）**不受视觉隐藏影响**。
  - 光标位于中心安全区时，依然能够正常识别中心停顿，松手时正常触发中心核圆动作或静默取消；向外拖拽超过死区半径后，依然以完全一致的数学判定进入外圈扇区。
  - 解耦理由：用户仅希望去除中心圆的视觉遮挡，而不希望改变既有的肌肉记忆和防手抖安全区。若关闭视觉的同时强行消除死区判定，用户轻微拖动就会误触扇区动作，造成极高的误触率。

### 2.2 控制台界面联动与配置保留

- **单向禁用而非清空值**：
  - 在控制台「外观样式」页面的「中心核心圆与图案文字设置」卡片中提供「显示中心核心圆」开关（`ShowCoreCircleCheckBox`）。
  - 当开关关闭时，下属的 `CoreDetailsPanel`（包含中心图标开关、图案类型选择、自定义图片、缩放与偏移滑动条、中心文字字体与色彩设置等）以及几何尺寸中的 `CoreRadiusSlider` 整体进入 `IsEnabled = false` 禁用状态，并调低半透明度（`Opacity = 0.5`）。
  - 所有下属配置项的已有数值（图片路径、图标类型、缩放比、文字颜色、半径等）**完全保留在内存与配置中，绝不清空**。
  - 用户重新勾选「显示中心核心圆」时，下属控件立刻恢复启用（`IsEnabled = true`，`Opacity = 1.0`），无需重新配置。

### 2.3 配置持久化与向前/向后兼容
- `AppConfig.ShowCoreCircle` 默认值为 `true`。
- 历史配置 JSON 缺失 `ShowCoreCircle` 键时，反序列化自动保持 `true`，完全保持向后兼容。
- `ConfigManager.ExportConfig` 与 `ImportConfig` 均通过完整 JSON 序列化无损导纳此字段。

## 3. 验证与人工验收关注点

### 3.1 自动化验证（无 GUI）

通过 `scratch/desktop-pet-core-tests/` 覆盖以下 27 项断言：
1. 默认配置反序列化及新建默认时 `ShowCoreCircle == true`。
2. 历史遗留 JSON（缺失该字段）自动默认赋值 `true`。
3. 显式设为 `false` 时的序列化/反序列化及完整导入/导出无损保留。
4. `CoreDeadzoneRadius` / `DragThreshold` 与命中距离阈值判定无损运行。
5. 控制台面板禁用/恢复联动模拟及数值防抹除验证。
6. 中/繁/英/日四语言字典词条存在性验证。

### 3.2 人工验收步骤与关注点
1. 打开控制台 -> 外观样式 -> 中心核心圆与图案文字设置 -> 取消勾选「显示中心核心圆」。
2. 观察右侧实时预览画布：中心核心圆应瞬间消失，呈现完全通透的空心环，且无任何残留边框或黑斑。
3. 观察下属控件：中心图案、文字、缩放滑动条等应变为半透明禁用状态；半径滑动条应同时禁用。
4. 点击保存更改，重新打开控制台或重新唤起轮盘：
   - 呼出轮盘后，中心应呈现通透空心；
   - 鼠标悬停中心松手：应能正常执行已配置的中心动作或静默取消；
   - 划过外圈扇区：扇区高亮正常，中心不应闪现文字或背景遮罩；
   - 调音手势：拖动调音时中心不应闪烁遮挡。
5. 重新勾选「显示中心核心圆」：中心圆与下属设置应完整无损恢复。
